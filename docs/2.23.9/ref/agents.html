class agents_handler : public eos::base_handler<agents_mgr, agents_handler>¶
#include <agents.h>

Handler for cross-agent state-change notifications. To watch ALL agents, call watch_all_agents(true). To watch specific agents, call watch_agent(name, true). These two modes are mutually exclusive (consistent with base_mgr). watch_all overrides any agent-specific watches.

class agents_mgr : public eos::base_mgr<agents_handler, std::string>¶
#include <agents.h>

Manager for reading other agents’ config and status. This manager provides read-only access to all agents’ config options and status keys. It doesn’t provide write access to other agents’ state. Agents communicate by writing to their own status and watching others’ status.

Watch registration is done on the handler (watch_all_agents/watch_agent).
